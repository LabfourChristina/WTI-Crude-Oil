# 天才交易员 · 原油模拟操盘

一款纯前端、本地离线可玩的原油交易模拟游戏。以 WTI 原油 2025-01-01 以来的真实行情骨架为底层数据，通过「下一天」逐步推进蜡烛图，体验保证金交易、加杠杆、强平爆仓与借低利贷东山再起（或上天台）的全过程。

> 双击 `index.html` 即可游玩（推荐 Chrome / Edge）。也可运行 `python -m http.server` 后访问本地端口。

---

## 玩法速览

| 入口 | 位置 | 说明 |
| --- | --- | --- |
| 低利贷 | 左上角 | 额度 ¥200,000，每日利息仅 1%，可借可还 |
| 新闻 | 右上角 | 查看带日期的原油国际大新闻；未读重要新闻会亮红点 |
| 下一天 | 右上角 | 推进一个交易日，按当日收盘价结算 |
| 买多 / 买空 | 右侧矩阵 & 右下角 | 输入金额并选杠杆（1/2/3/5/10 倍）下单 |
| 卖多 / 卖空 | 右侧矩阵 & 持仓卡片 | 按比例平仓、回收现金 |
| 现金区 | 右下角 | 实时存款余额（初始 ¥200,000） |

游戏进度不保存、不联网，关闭页面即归零重开。

## 交易规则（保证金 + 杠杆）

- 每方向（多 / 空）独立维护：**保证金 M**、**头寸系数 K**、**方向杠杆 L**。
- 开仓：从存款扣掉保证金 `A`，方向 `M+=A`、`K+=A/当日收盘价`。
- 多头权益 `E = M + L×(P·K − M)`；空头权益 `E = M + L×(M − P·K)`，`P` 为最新收盘价。
- 该方向全部持仓共用同一个杠杆档位；在下单弹窗点杠杆胶囊可**随时调档并立即生效**。
- 浮亏超过保证金（权益 ≤ 0）→ 强制平仓，多余亏损从现金中扣除（可能倒欠变负）。
- 买入不产生任何持仓费用；卖多 / 卖空即按比例平仓，取回现金。

## 低利贷

- 总额度 ¥200,000；借多少、应还多少实时更新。
- 每次点击「下一天」自动结算：应还金额按 1% 计息，利息并入欠款并继续滚息；需要通过还款操作主动偿还。
- 应还金额超过「现金 + 还可借额度」即宣告破产。

## 结局

- 现金归零且借无可借 → 「你没有钱了，天台见！」
- 低利贷彻底还不清 → 「你还不起低利贷了，天台见！」
- 两种结局均可点「重新开始」回到 2025-01-01。

## 数据说明

| 内容 | 来源 |
| --- | --- |
| 行情骨架 | FRED `DCOILWTICO` WTI 现货日度收盘（`fred_raw.csv`，免费免 Key） |
| 补齐 | 周末 / 美国休市 / 数据源截止后的自然日，按相邻真实值做对数线性桥接并叠加与真实波动匹配的微噪声 |
| 覆盖 | 2025-01-01 ~ 2026-09-06，共 614 根日线蜡烛（415 个真实交易日），每个自然日一根 |
| 新闻 | 2025 年段整理自真实国际原油大事件（OPEC+、关税、美伊制裁、中东冲突、飓风等）；2026 年段结合行情拐点整理的叙事性标题，标注「重要」的会触发红点与弹窗 |

> 提示：OHLC 中的高低价在非真实日为按波动估计的合成值；历史复盘请以 FRED 真实收盘为准。可运行 `python build_data.py` 重新生成 `js/data.js`（脚本读取本目录 `fred_raw.csv`，无需联网）。

## 玩法提示（作弊向，慎看）

- 想快速体验爆仓：全仓买多 + 10 倍杠杆，然后一路「下一天」直到价格跌 10%。
- 想活久一点：控制仓位，别把低利贷当成无限提款机（每日 1% 的复利很凶）。
- 重要新闻常是当日大波动的前兆——别在红点出现时满仓梭哈。
