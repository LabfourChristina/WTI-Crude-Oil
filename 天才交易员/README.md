# 天才交易员 · 原油模拟操盘

一款纯前端、本地离线可玩的原油交易模拟游戏。以 WTI 原油 2023-01-01 以来的真实行情骨架为底层数据，通过「下一天」逐步推进蜡烛图，体验保证金交易、加杠杆、强平爆仓与借低利贷东山再起（或上天台）的全过程。

> 双击 `index.html` 即可游玩（推荐 Chrome / Edge）。也可运行 `python -m http.server` 后访问本地端口。

---

## 交易规则（保证金 + 杠杆）

- 每方向（多 / 空）独立维护：**保证金 M**、**头寸系数 K**、**方向杠杆 L**。
- 开仓：从存款扣除保证金 `A`，方向 `M+=A`、`K+=A/当日收盘价`；开仓资金只能用现金，不能用低利贷额度直接开仓。
- 多头权益 `E = M + L×(P·K − M)`；空头权益 `E = M + L×(M − P·K)`，`P` 为最新收盘价。
- 同一方向全部持仓共用同一杠杆档位；下单弹窗里的杠杆胶囊**点选即生效**——不必下单也能实时把该方向整体调档，若调档后权益 ≤ 0 会立即触发强平。
- 每点一次「下一天」都会按最新收盘价重估：某方向浮亏耗尽保证金（权益 ≤ 0）→ **强制平仓**，超出保证金的亏损从现金中扣除，现金可能因此变为负数。
- 开平仓均不收取手续费；卖多 / 卖空为按比例平仓，平仓价值直接回收为现金。

## 低利贷

- 总额度 ¥200,000；可借额度与应还金额实时更新，支持「一键还清」。
- 每点一次「下一天」自动计息：按当前应还金额的 1% 计息并**并入欠款继续滚息**（复利）；贷款不会自动扣还，需要主动还款。
- 每次结算后都会判定破产：
  - 应还金额 > 「存款余额 + 持仓净值」→ 「你还不起低利贷了，天台见！」
  - 存款余额与持仓净值之和归零（如强平倒欠现金后）→ 「你没有钱了，天台见！」

## 对局与结局

- 每局固定 365 天：开局在行情数据范围内**随机锚定一天**（自动保证其后至少还有 365 天可走），左上角显示倒计时，每点一次「下一天」减 1。
- 走满 365 天仍未破产 → 正常收官「交易结束，恭喜你活到了最后！」，按「现金 + 持仓净值 − 应还贷款」结算，≤ 初始 20 万为保本，> 20 万为赚钱。
- 中途触发上述破产判定则直接进入天台结局。
- 收官或破产后均可点「重新开始」，开局日会重新随机锚定。

## 数据说明

| 内容 | 来源 |
| --- | --- |
| 行情骨架 | FRED `DCOILWTICO` WTI 现货日度收盘（`fred_raw.csv`，免费免 Key；含 2022-12 起少量上下文数据，真实值至 2026-09-01） |
| 补齐 | 周末 / 美国休市 / 数据源截止后的自然日（2026-09-02 ~ 09-06），按相邻真实值做对数线性桥接，并叠加与真实波动匹配的微噪声 |
| 覆盖 | 2023-01-01 ~ 2026-09-06，共 1,345 根日线蜡烛（913 个真实交易日），每个自然日一根 |
| 新闻 | 2023-2025 年段整理自真实国际原油大事件（OPEC+、银行业危机、中东冲突、红海局势、关税、美伊制裁、飓风等）；2026 年段结合行情拐点整理的叙事性标题；标注「重要」的会触发红点与到达当日弹窗 |

> 提示：OHLC 中的高低价在非真实日为按波动估计的合成值；历史复盘请以 FRED 真实收盘为准。可运行 `python build_data.py` 重新生成 `js/data.js`（脚本读取本目录 `fred_raw.csv`，无需联网）。

## 玩法提示（作弊向，慎看）

- 想快速体验爆仓：全仓买多 + 10 倍杠杆，然后一路「下一天」直到价格跌 10%。
- 想活久一点：控制仓位，别把低利贷当成无限提款机（每日 1% 的复利很凶）。
- 重要新闻常是当日大波动的前兆——别在红点出现时满仓梭哈。
